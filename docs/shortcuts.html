Keyboard and pointer reference

Every shortcut in the application. The same list is available in the app under Help → Keyboard Shortcuts.

Tools

ToolKeyUse
SelectionVMove the whole character; drag the advance line.
NodeASelect and drag anchors, handles and marquees.
PenPPlace corner points, or drag to pull smooth handles.
BrushBDrag freely; the stroke becomes an editable outline.
HandHPan the canvas.
ZoomZClick to zoom in, Alt-click to zoom out.

Navigation

ActionShortcut
Zoom around the pointerMouse wheel, or Ctrl+wheel
Zoom in / zoom outCtrl+= / Ctrl+-
Fit the character to the canvasCtrl+0
PanMiddle-drag, or H and drag
Previous / next character[ / ] or PageUp / PageDown

Editing

ActionShortcut
Undo / redoCtrl+Z / Ctrl+Y
Copy / paste a characterCtrl+C / Ctrl+V
Copy to another characterCtrl+D
Select every point in the contourCtrl+A
Add a point to the selectionShift+click
Constrain a move to one axisShift+drag
Break a smooth point while dragging a handleAlt+drag
Nudge by 10 units / 1 unitArrow keys / Shift+arrows
Delete the selected pointsDelete or Backspace
Finish a pen contourEnter
End a stroke, then deselectEscape

File

ActionShortcut
New fontCtrl+N
Open projectCtrl+O
Save projectCtrl+S
Export fontCtrl+E
While a text field has focus Shortcuts are suspended, so typing a character name or a number never triggers a tool. Click the canvas to give it focus again.
